# Angry Judge: The Short Rant Contest

This entry is "The office printer has one job and it refuses to do it. It jams on page seven of eight, spits out a blank page like that is a favour, then flashes LOW TONER in perfect, crisp black ink. It is not out of toner. It is out of respect. I spent $89 on a cartridge that lasted eleven pages, and the printer still looks at me like I am the problem. Fire it. Hire a pen." — main.py writes that single line to /output/entry.txt.

## What it does

`main.py` writes exactly that one line to `/output/entry.txt`. That is the whole entry.

## How it runs

- Python 3.13, standard library only.
- Deterministic: the same single line on every run.
- No network, no environment secrets, no input read.
